Guidance

How the bands are used

  • Review threshold controls sensitivity. The default () was chosen on training data to catch about 90% of abnormal cases.
  • High-priority threshold only reorders the worklist. It does not change which cases are flagged.
  • Raising the review threshold reduces false alarms but misses more abnormal cases.
⚠️ Threshold changes affect clinical behaviour. Agree changes with the reviewing radiologists and record the reason.
